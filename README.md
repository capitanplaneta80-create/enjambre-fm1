# ENJAMBRE · firmware para el M-VAVE FM-1

Insectos como agentes en un campo orbital, cuántico o atómico: un motor nuevo (`ENJAMB`) para
[Felucca](https://github.com/hugelton/Felucca) de Leo Kuroshita (Hügelton Instruments), sin afiliación con sus autores.

Este repositorio guarda solo lo que ENJAMBRE agrega o cambia (`overlay/`). GitHub Actions toma Felucca en un commit
fijo, aplica `overlay/`, compila el firmware y publica en GitHub Pages el sitio con el instalador web.

Autor de ENJAMBRE: Ph.D. Mauricio Vásquez Arias, profesor titular – investigador asociado, Escuela de Artes y
Humanidades, Universidad EAFIT. Licencia: GPL-3.0 (como Felucca). Software experimental, sin garantía.
M-VAVE y FM-1 son marcas de sus dueños.
